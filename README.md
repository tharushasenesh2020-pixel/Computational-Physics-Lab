## 🧪 Topics Covered

### 📐 Numerical Methods
- Solving **Ordinary Differential Equations** (Euler, Runge-Kutta methods)
- **Root finding** algorithms (Bisection, Newton-Raphson)
- **Vector and matrix** operations using NumPy
- Numerical integration and differentiation

### 📡 Signal Processing
- **Fourier Transform** analysis
- Frequency domain representation
- Signal decomposition and reconstruction

### 🌀 Chaos Theory
- **Logistic map** and bifurcation diagrams (discrete systems)
- **Lorenz attractor** and phase space analysis (continuous systems)
- Sensitivity to initial conditions
- Strange attractors and chaotic behaviour

### 🎲 Monte Carlo Methods
- **Random walk simulations**
- Statistical sampling and probability distributions
- Area estimation using Monte Carlo integration
- Particle simulation with random motion

### ⚛️ Molecular Dynamics
- **MD simulation** of particle systems
- Lennard-Jones potential
- Energy conservation and thermodynamic properties
- Trajectory analysis and visualisation

## 🚀 Running the Notebooks

### Prerequisites
Make sure you have Python 3 and the required libraries installed:

```bash
pip install numpy matplotlib scipy jupyter
```

### Launch Jupyter
```bash
jupyter notebook
```
Then navigate to any folder and open the `.ipynb` file of your choice.
